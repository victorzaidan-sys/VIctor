# Instruções de Instalação — Controle Universal TV

Siga o passo a passo abaixo para instalar o aplicativo `app-release.apk` no seu celular Android:

## Passo 1: Obter o arquivo APK
Após compilar com `./gradlew assembleRelease`, o arquivo estará localizado em:
`app/build/outputs/apk/release/app-release.apk`

## Passo 2: Transferir para o Celular
Envie o arquivo `app-release.apk` para o celular utilizando:
* Cabo USB
* Google Drive / Dropbox
* WhatsApp / Telegram
* Download direto no navegador do celular

## Passo 3: Autorizar e Instalar
1. No smartphone Android, acesse o aplicativo **Meus Arquivos** ou **Download**.
2. Toque no arquivo `app-release.apk`.
3. Se o Android exibir o aviso *"Por motivos de segurança, o seu telefone não tem permissão para instalar apps desconhecidos desta fonte"*:
   * Toque em **Configurações**.
   * Ative a chave **Permitir desta fonte**.
   * Volte e toque em **Instalar**.

## Passo 4: Conectar à TV
1. Certifique-se de que o Wi-Fi do smartphone está conectado na mesma rede da Smart TV.
2. Abra o aplicativo **Controle Universal TV**.
3. Toque no botão **Encontrar minha TV**.
4. Selecione a TV na lista para conectar e usar o controle remoto.
